# Talk2D2: A Star Wars Chat Experience 🌟

Welcome to a chat app from a galaxy far, far away... 

## 🚀 About Talk2D2

Ever wanted to chat with your favorite Star Wars characters? Well, now you can! Talk2D2 is a real-time chat application where you can:

- Join themed channels like #star-wars, #rebel-alliance, or create your own
- Chat with fellow Star Wars enthusiasts
- Share messages, reactions, and attachments
- Create threads (just like sending a transmission to the Death Star)
- See who's online in the galaxy (green lightsaber) or who's away (gray like carbonite)

## 🤖 Featured Characters

Our chat rooms are frequented by some familiar faces:
- Luke Skywalker (when he's not busy with Jedi training)
- Darth Vader (between Death Star inspection rounds)
- Princess Leia (diplomatic missions permitting)
- Han Solo (if he's not making the Kessel Run)
- Chewbacca (roars translated automatically)

## 🛸 Getting Started

1. Clone this repository faster than the Millennium Falcon
2. Install dependencies (no need for power converters from Tosche Station)
3. Set up your Supabase credentials
4. Run `npm run dev` to fire up your hyperdrive

## 🌌 Features

- **Real-time messaging**: Faster than a Force message
- **Thread Discussions**: More organized than the Jedi Archives
- **User Statuses**: Know who's online (green like Yoda) or offline (gray like the dark side)
- **File Sharing**: Share plans (Death Star or otherwise)
- **Reactions**: Express yourself better than a Wookiee

## 🎮 Tech Stack

- Next.js (More powerful than a lightsaber)
- Supabase (Better than a Jedi holocron for storing data)
- React (As reactive as R2-D2)
- TypeScript (Bringing balance to the code)
