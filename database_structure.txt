# Slack Clone Database Structure

## Tables (with example data)

### public.users
- id (uuid) PRIMARY KEY REFERENCES auth.users(id)
- username (text)
- status (user_status) DEFAULT 'OFFLINE'
- avatar_url (text) NULLABLE
- updated_at (timestamptz)
Example: {id: '2a219aa0-...', username: 'user1', status: 'OFFLINE', avatar_url: 'https://...storage/avatars/...'}

### public.channels
- id (bigint) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- slug (text) NOT NULL UNIQUE
- inserted_at (timestamptz) DEFAULT timezone('utc'::text, now()) NOT NULL
- created_by (uuid) REFERENCES auth.users(id) NOT NULL
Example: {id: 1, slug: 'public', created_by: '8d0fd2b3-...', inserted_at: '2025-01-07 04:26:04'}

### public.messages
- id (bigint) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- message (text)
- user_id (uuid) REFERENCES public.users(id) NOT NULL
- channel_id (bigint) REFERENCES channels(id) ON DELETE CASCADE NOT NULL
- inserted_at (timestamptz) DEFAULT timezone('utc'::text, now()) NOT NULL
- parent_id (bigint) REFERENCES messages(id) NULLABLE
- attachments (jsonb) NULLABLE
Example: {id: 1, message: 'Hello World 👋', user_id: '8d0fd2b3-...', channel_id: 1}

### public.direct_messages
- id (bigint) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- content (text) NOT NULL
- sender_id (uuid) REFERENCES auth.users(id) ON DELETE CASCADE
- recipient_id (uuid) REFERENCES auth.users(id) ON DELETE CASCADE
- attachments (jsonb) NULLABLE
- inserted_at (timestamptz) DEFAULT timezone('utc'::text, now()) NOT NULL
- updated_at (timestamptz) DEFAULT timezone('utc'::text, now()) NOT NULL
Example: {id: 1, content: 'hi!', sender_id: '2a219aa0-...', recipient_id: 'f5392b1e-...'}

### public.message_reactions
- id (bigint) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- message_id (bigint) REFERENCES messages(id)
- user_id (uuid) REFERENCES auth.users(id)
- emoji (text)
- created_at (timestamptz)

### public.role_permissions
- id (bigint) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY
- role (app_role) NOT NULL
- permission (app_permission) NOT NULL
- UNIQUE (role, permission)
Example: {id: 1, role: 'admin', permission: 'channels.delete'}

## Storage Buckets
- avatars: Public bucket for user profile pictures
  - Policies: authenticated uploads, public read, owner delete/update
- message_attachments: Public bucket for message files
  - Policies: authenticated uploads, public read, owner delete/update

## Active Realtime Subscriptions
- channels
- messages
- direct_messages
- users (for status updates)

## Database Functions
- authorize(requested_permission app_permission, user_id uuid): boolean
- auto_set_offline(): trigger
- handle_new_user(): trigger
- handle_updated_at(): trigger

## Custom Types
- app_permission: ENUM ('channels.delete', 'messages.delete')
- app_role: ENUM ('admin', 'moderator')
- user_status: ENUM ('ONLINE', 'OFFLINE')
