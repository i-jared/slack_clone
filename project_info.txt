# Talk2D2 - Star Wars Themed Chat Application

## Tech Stack Overview

### Frontend
- Next.js (React Framework)
- TailwindCSS for styling
- Star Wars themed UI with custom animations and effects
- Custom fonts including Star Wars font (Starjedi.ttf)

### Backend
- Supabase for:
  - Authentication
  - Real-time database
  - Row Level Security (RLS)
  - Storage for avatars and attachments

### Database Structure
Tables:
1. channels
2. message_reactions
3. messages
4. role_permissions
5. user_roles
6. users

Storage Buckets:
1. avatars (Public)
2. message_attachments (Public)

### Key Features
1. Real-time Chat
   - Channel-based messaging
   - Message reactions
   - File attachments
   - Real-time updates

2. Authentication & Authorization
   - Email-based authentication
   - Role-based access control (admin, moderator)
   - Custom user roles and permissions

3. Star Wars Theme
   - Animated starfield background
   - Flying ships animation
   - Star Wars sound effects
   - Themed UI components
