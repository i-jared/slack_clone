## **Relationships and Constraints**

- **Primary Keys**: Each table has a primary key (`id`) that uniquely identifies each record.
- **Foreign Keys**:
  - `channels.created_by` references `users.id`
  - `direct_messages.sender_id` and `direct_messages.recipient_id` reference `users.id`
  - `message_reactions.message_id` references `messages.id`
  - `message_reactions.user_id` references `users.id`
  - `messages.user_id` references `users.id`
  - `messages.channel_id` references `channels.id`
  - `user_roles.user_id` references `users.id`
- **Nullable Fields**: 
  - `attachments` in `direct_messages` and `messages` tables can be `NULL` if there are no attachments.
  - `parent_id` in `messages` is nullable to allow for threaded messages.
  - `avatar_url` in `users` can be `NULL` if the user hasn't set an avatar.
