DATABASE SCHEMA AND STRUCTURE:

Tables:
1. direct_messages
- id (bigint, PK)
- sender_id (uuid, FK -> users)
- recipient_id (uuid, FK -> users)
- message (text)
- attachments (jsonb)
- inserted_at (timestamptz)
- updated_at (timestamptz)

2. messages
- id (bigint, PK)
- inserted_at (timestamptz)
- message (text)
- user_id (uuid, FK -> users)
- channel_id (bigint, FK -> channels)
- attachments (jsonb)
- parent_id (bigint, FK -> messages)

3. users
- id (uuid, PK)
- username (text)
- status (user_status)
- avatar_url (text)
- updated_at (timestamptz)

4. channels
- id (bigint, PK)
- inserted_at (timestamptz)
- slug (text)
- created_by (uuid, FK -> users)

Relationships:
- direct_messages.sender_id -> users.id
- direct_messages.recipient_id -> users.id
- messages.user_id -> users.id
- messages.channel_id -> channels.id
- messages.parent_id -> messages.id (self-referential)
- channels.created_by -> users.id

Enums:
- user_status: ONLINE, OFFLINE
- app_role: admin, moderator
- app_permission: channels.delete, messages.delete

Storage Buckets:
1. avatars
- Public: false
- File size limit: 5MB
- Allowed file types: .jpg, .jpeg, .png, .gif
- Access: Authenticated users only
- Path format: {user_id}/{timestamp}-{filename}.{ext}

2. message_attachments
- Public: false
- File size limit: 5MB
- Allowed file types: .jpg, .jpeg, .png, .gif, .pdf
- Access: Authenticated users only
- Path format: {user_id}/{timestamp}-{filename}.{ext}

Common Queries:
1. Get user's direct messages:
```sql
SELECT * FROM direct_messages 
WHERE sender_id = :user_id OR recipient_id = :user_id
```

2. Get channel messages:
```sql
SELECT * FROM messages 
WHERE channel_id = :channel_id
```

3. Get threaded replies:
```sql
SELECT * FROM messages 
WHERE parent_id = :message_id
```

Security:
- Row Level Security (RLS) enabled on all tables
- Storage access controlled by user_id
- File uploads restricted by type and size
- Authentication required for all operations

Performance:
- Indexes on all foreign key columns
- Composite indexes for frequent queries
- JSONB for flexible metadata
- Timestamp fields for tracking

Development Notes:

- Cascade deletes configured

Error Handling:
